# Requirements

## 1. Overview

Kiss Wall 是一个暗色浪漫的移动端社交仪式。玩家在纯黑画布上连续留下唇印；第一次触碰立即锁定一种骸骨、心脏、古典胸像、眼睛、手、玫瑰、面纱或羽翼主题，并在后台生成一张黑白“英雄标本”肖像。达到 12 个真实吻且图片就绪后，黑幕自动绽开，作品写入个人历史并进入公共墙。

一次创作约 30 秒至 2 分钟，也可只浏览公共墙、点赞、留言或在别人的作品上发起 kiss-back。最近 10 件作品、累计封印数、累计吻数与留言跨次保存。自然停止点是一次肖像绽开或浏览完墙；回访理由是创作新主题、查看他人回应，以及在别人的作品上叠加第二次“献吻”。

## 2. Visual Design

- 主体验是近乎全黑的竖屏暗房，粉色实体唇印是唯一持续的高饱和元素。
- AI 肖像为 512×768 的单主体黑白银盐质感；纯黑背景、左上轮廓光、无环境、无文字。
- 生成进行时，玩家的每次触碰都会切开一小块暗幕并留下唇印；揭晓后粉色唇印覆盖在高对比灰阶肖像上。
- 公共墙与详情延续墓碑、档案与细线框语言；所有功能图标使用自制 SVG。
- 具体系统见 `doc/visual.md`。

## 3. Game Mechanics

- 会话开始随机选择 `8` 种主题之一；首触锁定主题、首吻位置与是否 kiss-back，并同时启动肖像生成和一句 `6–12` 词英文墓志铭生成。
- 所有真实触碰都被接受，不再做轮廓命中/落空判定。首触前有 `4` 个位置组成的幽灵手指演示，每步 `1100 ms`，一轮后休息 `800 ms`；演示吻不会启动生成或计入结果。
- 当真实吻达到 `12` 个且图片请求结束后，再等待 `700 ms` 自动绽开；无需额外 Seal 按钮。
- 初次作品走 AlterU 媒体服务 `text` 模式；kiss-back 以父作品作为唯一公开 HTTPS 参考，走 `edit` 模式并保留同一单主体、轮廓和构图。两者均输出 `512×768`。
- 共享媒体客户端最多执行一次受控重试；失败后仍允许达到绽开状态并显示失败卡，不写入损坏作品，玩家可重开会话。
- 成功作品保存实际吻数组、主题、墓志铭、时间、肖像 URL 与 kiss-back 父信息；个人历史最多 `10` 件。
- 玩家可浏览公共墙、打开作者资料、给作品点赞、留下最多 `140` 字留言，并在他人作品上发起 kiss-back。个人存档最多保留最近 `30` 条留言。
- kiss-back 成功后向父作品作者发送一次通知；自身或无作者作品不触发跨用户通知。

## 4. Controls

- Pointer / Touch：在主画布按下即放置一个真实吻；使用统一 pointer 输入，单次触碰只计一次。
- Click：公共墙卡片、详情操作、作者资料、点赞、留言、再来一次与返回按钮使用 click，以保留滚动能力。
- Keyboard：留言输入框按 Enter 提交；没有方向键、拖拽或多点手势要求。
- 首次触碰会初始化音频；后续触碰始终先给出视觉反馈，不等待网络。

## 5. Win / Lose Conditions

没有胜负、得分、生命值、倒计时或 Game Over。一次创作的完成条件是达到 12 个真实吻且肖像生成完成后自动绽开。媒体失败不会形成惩罚或消耗资源：失败卡允许玩家重新开始，墙和详情仍可使用。玩家也可在任何时候只浏览公共墙后自然离开。

## 6. Sound Effects

- 六种 kiss 声都由 `25 ms` 左右的带通白噪点击与正弦 formant 扫频组成；基频约 `68–102 Hz`，上扫到约 `136–224 Hz`，总长约 `82–118 ms`。
- UI 点击使用约 `2400 Hz` 带通噪声短 tick，衰减约 `40 ms`，并在支持设备上触发默认 `8 ms` 轻震动。
- AudioContext 只在第一次用户手势创建并 resume 一次；白噪 buffer 预分配复用，同时发声上限为 `8`，超限直接丢弃而不排队。
- 音频不可用时静默降级，视觉触碰、生成和保存不受影响。
