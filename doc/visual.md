# 视觉规范 — Kiss Wall

## 1. 视觉命题

在一块几乎看不见的黑色纪念墙上，玩家用真实唇印“显影”一件银盐标本。记忆点是第十二个吻落下后，黑幕缓慢绽开，粉色吻痕下出现冷峻肖像。必须浪漫、克制、触觉明确；避免恐怖血浆、廉价哥特滤镜和通用 AI 肖像。

## 2. 构图与镜头

- `390×844` 与 `320×568` 竖屏优先，平台内构图不为外部访客栏预留空间。
- 512×768 肖像垂直居中，单主体占画面高度约 `65–80%`；HUD 贴近安全区但不压住吻痕与主体。
- 背景没有场景、地平线或第二物体；主光从左上形成单一轮廓光，阴影落入纯黑。

## 3. 色彩

- 背景 `#07070A` / `#050507`，面板 `#14141D`，主强调 `#F5B1C7`。
- 生成肖像严格只使用黑、白、银灰；唇印使用粉/酒红变体形成唯一彩色层。
- 禁止生成图出现红花、绿色叶片、肤色、棕褐或 sepia；禁止大面积粉色渐变背景。

## 4. 字体

- Cormorant Garamond 用于墓志铭与仪式性标题；Inter 用于正文和控件；Montserrat 用于短标签；JetBrains Mono 用于统计。
- 墓志铭使用小写斜体、`6–12` 个英文单词；不把文字烘焙进生成图片。
- 中文回退到系统衬线/无衬线字体，按对应角色保持层级。

## 5. 形状、材质与光线

- 主材质是黑色石面、银盐相纸与半透明唇膏印；边框细、阴影深、圆角克制。
- 肖像必须有清晰的解剖/植物/织物表面细节和左上硬轮廓光，背景保持绝对黑。
- 禁止玻璃拟物、霓虹描边、金属镀铬、雾化彩色光和厚重卡通外轮廓。

## 6. 角色、环境与素材

- `lip-1.png` 至 `lip-6.png` 是运行时唇印；旋转约 `-16°–16°`、缩放约 `0.78–1.12`、透明度约 `0.82–1.0`。
- 八种主题只能出现一个主体：skull、heart、bust、eye、hand、rose、veil、wings。不能补全不存在的身体、手持者或第二朵花。
- 初次 text 生成与 kiss-back edit 均为 512×768 PNG；edit 必须保留父作品主体、轮廓、姿态和镜头，只细微增强情绪与质感。

## 7. UI 与图标

- HUD 和公共墙功能图标统一使用 `assets/icons.tsx` 自制 SVG，触控目标至少 `44×44 CSS px`。
- 画布使用 pointerdown；滚动墙、详情和留言操作使用 click。
- 生成中显示明确状态；失败保留“再吻一次”入口；成功后只突出“再来一次”和打开墙。
- 禁止 Emoji 充当任何功能图标。

## 8. 动效与特效

- 首触立即落下唇印；每个后续吻以短促缩放/透明度形成触觉响应。
- 达标与图片就绪后等待 `700 ms` 再绽开，给最后一个吻留出完整落点。
- 幽灵手指只在首触前演示，不永久循环干扰玩家。
- `prefers-reduced-motion` 下取消漂移和大幅缩放，以遮罩透明度变化完成揭晓。

## 9. 参考转译原则

- 银盐标本摄影提供冷峻材质；墓碑与纪念墙提供永久性；唇膏印提供亲密触觉。
- 只转译材质、仪式和单主体陈列，不复制现实摄影品牌、宗教符号或具体墓碑设计。

## 10. 反模式

- 禁止彩色 AI 肖像、环境场景、第二主体、手持物、文字、水印、边框和渐变光晕。
- 禁止把吻做成命中/落空惩罚；每次真实触碰都必须被接纳。
- 禁止血浆、跳吓、卡通嘴唇 Emoji、通用玻璃卡片和访客栏驱动的永久下移。

## 11. 垂直切片验收

- 首屏在 200 ms 内出现幽灵手指示范；玩家首触立即留下可见唇印并开始生成。
- 第 12 个吻后等待媒体，状态清晰且界面不冻结；成功图与粉色唇印对比足够。
- 首张 text 输出是单主体灰阶标本；kiss-back edit 保留同一主体和构图，不新增对象。
- 公共墙、详情、点赞、留言和 kiss-back 在 `390×844` 与 `320×568` 可滚动、无横向溢出。
- 生成失败不写入破图，可重新开始且既有墙仍可浏览。
